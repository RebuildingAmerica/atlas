---
title: "Install Scout"
description: "Install the Scout CLI and verify the local command."
---

Scout is packaged as the `atlas-scout` Python application and exposes the
`scout` command.

## Current Install Path

Until the Homebrew tap is published, install Scout from the Atlas repository:

```bash
brew install python@3.12 uv
```

```bash
git clone https://github.com/RebuildingAmerica/atlas.git
cd atlas

uv tool install --reinstall --editable ./scout \
  --with-editable ./libs/shared \
  --with-editable ./libs/discovery-engine
```

Verify the command:

```bash
scout --help
```

## Requirements

- Python 3.12 or newer.
- `uv` for the current source install path.
- A local model provider, such as LM Studio or Ollama, for normal local
  discovery.
- Chromium for the optional JavaScript-rendered page fallback.
- A search key for search-backed discovery.
- An Atlas account only when you want login, sync, or worker mode.

Scout stores configuration and local data in OS-standard user directories. Run:

```bash
scout db path
scout config show
```

Install the optional headless browser used for JavaScript-rendered pages:

```bash
uvx --from playwright playwright install chromium
```

## Homebrew Target

The intended public install path is a RebuildingAmerica Homebrew tap:

```bash
brew install rebuildingamerica/tap/atlas-scout
```

That tap is not published yet. Until it exists, use the source install path
above. The tap should install only the production `scout` command; `scout-dev`
is for contributors working inside the Atlas repository.

## Optional Shell Integration

Scout can install shell completion and local man pages:

```bash
scout setup --install-completion --install-man
```

Use explicit directories when your shell environment needs them:

```bash
scout setup \
  --install-completion \
  --completion-shell zsh \
  --completion-dir ~/.zfunc \
  --install-man \
  --man-dir ~/.local/share/man/man1
```

## Next Step

Run the setup flow:

```bash
scout setup
```
