## Overview

Once you've connected an AI assistant to Atlas ([setup guide](/mcp/overview)), these tools are available in your conversations.

You don't need to call these tools directly — your AI assistant uses them automatically when you ask relevant questions. The reference below helps you understand what's possible and craft more effective prompts.

For guided workflows exposed through your client's prompt or slash-command
picker, see [Available prompts](/mcp/prompts).

Some tool responses include `resource_uri` values. For supported URI families,
clients can use `resources/read` to fetch that artifact again as durable
context. See [Available resources](/mcp/resources).

<Note>
  Tool access depends on your plan, OAuth scopes, and workspace. See
  [Scopes and permissions](/mcp/scopes), [Authentication](/api/authentication),
  and [Workspace integration activity](/workspace/integration-activity) when a
  tool is missing or returns a permission error.
</Note>

## Entity tools

### search_entities

Search Atlas entities by place, topic, or free text.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `place` | string | Natural-language place or normalized place key |
| `issue_areas` | string[] | Issue area slugs to filter by |
| `text` | string | Free-text search query |
| `entity_types` | string[] | Filter by type: `person`, `organization`, `initiative`, `campaign`, `event` |
| `source_types` | string[] | Filter by source type |
| `limit` | integer | Max results (default: 20) |
| `cursor` | string | Pagination cursor from a previous response |

**Example prompts:**
- "Find labor organizers in Detroit"
- "Search for organizations working on housing affordability in Kansas City"
- "Who's working on climate issues in rural Montana?"

### get_entity

Get full details for a specific entity by ID.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `entity_id` | string | The entity's unique ID |
| `relation_types` | string[] | Optional relationship types to include |
| `limit` | integer | Max results (default: 20) |

**Example prompts:**
- "Tell me more about that first organization"
- "Get the full details for Prairie Workers Cooperative"

### get_entity_sources

Get all sources backing a specific entity.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `entity_id` | string | The entity's unique ID |
| `limit` | integer | Max results (default: 20) |
| `cursor` | string | Pagination cursor from a previous response |

**Example prompts:**
- "What are the sources for KC Tenants?"
- "Show me where this information came from"

### get_related_entities

Find entities related through Atlas relationships.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `entity_id` | string | The entity's unique ID |
| `limit` | integer | Max results (default: 20) |
| `cursor` | string | Pagination cursor from a previous response |

**Example prompts:**
- "Who else is connected to this organization?"
- "What other entities are related to Maria Gonzalez?"

## Source tools

### search_sources

Search across all Atlas sources.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `place` | string | Place filter, such as `Kansas City, MO` |
| `issue_areas` | string[] | Issue area slugs to filter by |
| `text` | string | Free-text search query |
| `source_types` | string[] | Filter by type: `journalism`, `nonprofit_listing`, `organizational_website`, etc. |
| `limit` | integer | Max results (default: 20) |
| `cursor` | string | Pagination cursor from a previous response |

**Example prompts:**
- "Find news articles about tenant organizing in Kansas City"
- "Search for nonprofit listings related to environmental justice"

## Place tools

### get_place_entities

Get entities for a specific place. Alias for `search_entities` with a place filter.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `place` | string | Natural-language place or normalized place key |
| `issue_areas` | string[] | Issue area slugs to filter by |
| `text` | string | Free-text search query |
| `entity_types` | string[] | Entity types to include |
| `source_types` | string[] | Source types to include |
| `limit` | integer | Max results |
| `cursor` | string | Pagination cursor from a previous response |

**Example prompts:**
- "What civic organizations are active in Boise, Idaho?"
- "Show me all entities in Kansas City working on housing"

### get_place_profile

Get demographic and socioeconomic context for a place.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `place` | string | Natural-language place or normalized place key |

**Example prompts:**
- "What's the demographic profile of Garden City, Kansas?"
- "Tell me about the socioeconomic context of this city"

### get_place_coverage

Get coverage gaps and entity counts for a place.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `place` | string | Natural-language place or normalized place key |
| `issue_areas` | string[] | Optional issue area slugs to focus the coverage summary |

**Example prompts:**
- "What issue areas are underrepresented in Kansas City?"
- "Where are the coverage gaps in Boise?"
- "Which issues have the most entities in Detroit?"

### get_place_issue_signals

Get an issue area summary for a place.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `place` | string | Natural-language place or normalized place key |
| `issue_areas` | string[] | Optional issue area slugs to include |
| `top_entities_per_issue` | integer | Number of example entities per issue (default: 5) |

**Example prompts:**
- "What are the main civic issues in Kansas City?"
- "Give me an issue area breakdown for this city"

## Research run tools

### list_discovery_runs

List source-linked Atlas research runs and their structured outputs.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | string | Optional state filter, such as `MO` |
| `status` | string | Optional run status filter |
| `limit` | integer | Max runs to return (default: 20) |
| `cursor` | string | Pagination cursor from a previous response |

**Example prompts:**
- "Show recent completed research runs in Missouri"
- "What research has Atlas run for this state?"

### get_discovery_run

Get one source-linked Atlas research run and its structured output.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `run_id` | string | The research run ID |

**Example prompts:**
- "Open that research run"
- "Summarize the entities and sources from this run"

### start_discovery_run

Trigger a new Atlas research run for a place and issue areas. Unlike the other tools, this one does real work — it kicks off the same LLM extraction and source-fetching pipeline behind the Atlas dashboard, which can take minutes rather than seconds.

Because of that, `start_discovery_run` requires an MCP client that supports the [MCP Tasks extension](https://tasks.extensions.modelcontextprotocol.io/specification/draft/tasks): the call returns a task handle immediately, and your assistant polls it until the run finishes rather than blocking. If your client doesn't support tasks yet, use `list_discovery_runs`/`get_discovery_run` to check on runs you started elsewhere (like the dashboard).

This tool requires the `discovery:write` scope, on top of the `discovery:read` + `api.mcp` scopes every other tool needs, and it's metered against your org's monthly discovery-run budget — see [Scopes and permissions](/mcp/scopes).

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `location_query` | string | Location to research, such as `Kansas City, MO` |
| `state` | string | 2-letter state code |
| `issue_areas` | string[] | Issue area slugs to research |
| `research_goal` | string | Research focus (default: `landscape_scan`) |

**Example prompts:**
- "Start a new research run for civic organizations in Topeka, Kansas"
- "Research worker cooperatives in Wichita — I don't see much coverage yet"
