The MCP Registry is a public metadata catalog for MCP servers. Atlas has prepared the metadata for registry-aware discovery, but the listing has not been published.

<Note>
  Atlas is not active in the official MCP Registry yet. The prepared manifest is
  ready for review, but it has not been submitted or published.
</Note>

## Prepared metadata

| Field         | Value                                        |
| ------------- | -------------------------------------------- |
| Namespace     | `org.rebuildingus.atlas/atlas`               |
| Title         | `Atlas`                                      |
| Website       | `https://atlas.rebuildingus.org`             |
| Repository    | `https://github.com/RebuildingAmerica/atlas` |
| Repository ID | `1206079057`                                 |
| Server URL    | <McpServerUrl />                             |
| Transport     | `streamable-http`                            |
| Version       | `0.1.0`                                      |
| Authorization | OAuth through compliant MCP clients          |

The prepared manifest lives in `mcp/server.json`. It includes the public Streamable HTTP remote, homepage, source repository metadata, and deployed PNG icons. It intentionally does not include manual authorization headers because Atlas relies on OAuth discovery and authorization challenges for compliant clients.

## Current status

| Check                     | Status                                        |
| ------------------------- | --------------------------------------------- |
| Official registry listing | Not published                                 |
| Prepared `server.json`    | Ready in the repository                       |
| Remote endpoint           | Public Atlas production URL                   |
| Registry namespace        | Prepared under `org.rebuildingus.atlas/atlas` |
| Publication approval      | Pending maintainer approval                   |

Once the listing is published and verified, registry-aware clients and downstream catalogs can discover Atlas by name or namespace. Until then, compliant clients connect directly to the server URL.
