---
title: Self-hosting Atlas
---

Atlas runs as a Cloudflare Worker for the web application and a persistent API
service for discovery work. The web deployment needs a public HTTPS origin,
the API proxy target, and the same authentication and billing settings used by
the application.

For a local or private deployment, run the API in a persistent container or VM
with PostgreSQL. Discovery jobs are long-running and require durable storage.
Configure the web application with `ATLAS_PUBLIC_URL` and
`ATLAS_SERVER_API_PROXY_TARGET`, then publish the Worker with the repository’s
Cloudflare build path.

Use Stripe test mode for staging and live mode only after checkout, webhook,
and entitlement changes have been verified at the deployed origin.
