# Support

Atlas is a public civic technology project for finding source-linked people,
organizations, and initiatives working on public problems.

## Use Atlas

Use the public product at
[atlas.rebuildingus.org](https://atlas.rebuildingus.org).

For product, API, MCP, Scout, and self-hosting guidance, start with the public
docs at [atlas.rebuildingus.org/docs](https://atlas.rebuildingus.org/docs).

## Work On The Repository

For local development, start with:

- [README.md](./README.md)
- [CONTRIBUTORS.md](./CONTRIBUTORS.md)
- [Getting Started](./docs/getting-started/README.md)
- [Development Workflow](./docs/development/workflow.md)

## Report Problems

Pull requests that improve docs, setup, tests, self-hosting, or public-safe
product behavior are welcome.

For docs and setup fixes, include the page, command, expected result, and actual
result. For product behavior, include the route, public-safe reproduction steps,
and whether the problem affects source evidence or confidence.

## Security And Sensitive Data

Do not post secrets, credentials, private data, or sensitive personal
information publicly. Follow [SECURITY.md](./SECURITY.md) for vulnerabilities or
sensitive data exposure.
