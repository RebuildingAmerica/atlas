# Atlas Product Documentation

Atlas product docs translate the project vision into concrete product contracts.
They sit between the canonical roadmap and implementation plans.

Start here:

- [Experience First](../experience-first.md) governs every product decision.
- [Atlas Roadmap](../roadmap.md) is the source of truth for product direction.
- [PRD Suite](./prds/README.md) defines the experience-first product surfaces.

The PRDs are intentionally journey-led. Atlas is not a generic enterprise
workspace with a public directory bolted on. The public experience of finding,
trusting, and acting on civic information is the product.
