# Legal collateral

Templates for a buyer or a regulator. Each document states its own review status
in its first lines.

| Document                                                  | Send it when                                      |
| --------------------------------------------------------- | ------------------------------------------------- |
| [Data Processing Addendum](./data-processing-addendum.md) | An enterprise buyer asks for a DPA before signing |

The Terms of Service and Privacy Policy live in `app/src/platform/pages/`,
beside the code whose behaviour they describe.
