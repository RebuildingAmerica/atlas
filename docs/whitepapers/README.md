# Atlas Whitepapers

Publishable position pieces on Atlas's model and principles. In
[Diátaxis](https://diataxis.fr/) terms these are **explanation** — the
discursive _why_ behind Atlas, written for a public audience and intended for
later publication. Each paper is a canonical in-repo artifact first; publishing
it (for example through the Mintlify site) is a downstream step, not a fork.

Every paper must stay consistent with
[Experience First](../experience-first.md), the
[Product Vision](../the-atlas-product.md), and the public trust standard.
Internal-only framing — private founder or investor shorthand, unshipped
specifics, revenue targets — stays out of these files.
