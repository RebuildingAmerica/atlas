# Scout People Discovery Proof Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** Prove that Scout can independently discover, extract, review, and sync
real people-centered civic data through the `scout-dev` CLI, with all work
performed from an isolated git worktree.

**Worktree:** `/Users/williecubed/Projects/RebuildingAmerica/atlas-scout-proof`

**Branch:** `scout/people-discovery-proof`

**User outcome:** Atlas users need source-linked people records with enough
context to understand why a person matters in a place. This proof is successful
only if Scout produces person entries with descriptions, issue/place context,
and public source provenance without relying on a source-specific bulk import.

**Hard constraints:**

- All code changes, docs, tests, Scout runs, and commits happen inside the
  worktree above.
- The only ingestion path is `scout-dev`.
- Do not write directly to the Scout database.
- Do not use IRS/FEC/OpenStates-style structured imports as the proof path.
- Browser/manual web access is allowed only for debugging or verification, not
  as a bypass around Scout.
- Keep changes production-useful for ordinary Scout operators.

---

## Current Findings

- `scout-dev` defaults to the main checkout unless
  `SCOUT_DEV_SCOUT_PROJECT=/Users/williecubed/Projects/RebuildingAmerica/atlas-scout-proof/scout`
  is set.
- `scout-dev doctor --json` reports direct URL runs and Atlas sync ready.
- Search-backed discovery is not connected in this environment because no
  `SEARCH_API_KEY` is present.
- The active Scout config already has link following and bounded headless
  browser fallback enabled.
- The public CLI no longer exposes a source-specific `source import` command.
- `entries stats --json --run-id ...` can verify source-backed people counts,
  but `entries list` needs run-scoped and random sampling support to produce a
  trustworthy people sample through the CLI.

## Task 4: Run Real Scout Jobs

**Commands:**

```bash

  scout-dev --config .scout-proof/scout.toml run \
  --file .scout-proof/seeds/las-vegas.txt \
  --location "Las Vegas, NV" \
  --issues housing_affordability,public_transit,public_health,k12_education \
  --follow-links \
```
