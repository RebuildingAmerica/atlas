# Code Of Conduct

Atlas is civic technology. Contributors should be able to ask basic questions,
challenge assumptions, report problems, and improve public-interest software
without being treated poorly.

## Expected Behavior

- Be respectful, direct, and constructive.
- Assume good faith while still naming risks clearly.
- Make room for newcomers, non-specialists, and people with different civic,
  technical, or local knowledge.
- Treat public data about real people with care.
- Keep disagreements focused on the work, evidence, and user impact.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information, secrets, credentials, or sensitive personal
  details.
- Deliberately misleading reports, fabricated evidence, or abuse of issue and
  review processes.
- Repeated disruption after maintainers have asked for a behavior to stop.

## Enforcement

Maintainers may edit, hide, close, or delete comments and contributions that
violate this code of conduct. They may also limit participation when needed to
protect contributors, people represented in Atlas data, or the project itself.

If a concern involves a security vulnerability or sensitive data exposure, use
[SECURITY.md](./SECURITY.md) instead of posting publicly.
